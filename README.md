# VITrack - Smart Academic Planner

> **Note**: This repository is public for portfolio and demonstration purposes. You are welcome to review the code to evaluate my skills, but please do not copy, deploy, or reuse this code for personal or commercial projects.

VITrack is a smart academic planner and calculator built specifically for VIT students. It helps track grades, estimate CGPA targets, and optimize exam scores with a premium, user-friendly interface.

## Features
- **GPA Calculator:** Calculate semester GPAs based on credits and expected grades.
- **CGPA Calculator:** Instantly predict cumulative CGPA.
- **Target CGPA Planner:** Plan the required grades to hit target CGPAs.
- **FAT Marks Calculator:** Determine the exact written exam score needed to pass.

## Technologies Used
- React + Vite
- JavaScript / JSX
- CSS (Custom Variables, Animations, Responsive Design)
- Bootstrap 5 (Grid System)
